# PULSE Dance Studio

## Project Description

PULSE Dance Studio is a responsive multi-page website created for the Web Technologies 1 (Front End) course.

This project is a continuation of our Midterm Project. For the Endterm, we improved the existing website by adding JavaScript functionality, DOM manipulation, event handling, form validation, and jQuery.

The website provides information about our dance studio, dance classes, instructors, weekly schedule, and contact details.

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- jQuery
- Media Queries

## Website Pages

**1. Home — index.html**

The homepage introduces PULSE Dance Studio and displays available dance classes.

Endterm features:
- Dynamic class cards created using JavaScript
- Class filtering
- DOM manipulation

**2. About — about.html**

The About page introduces the dance studio and its instructors.

Endterm features:
- Interactive instructor cards
- Show and hide details
- jQuery effects

**3. Classes — classes.html**

The Classes page provides information about different dance styles.

Endterm features:
- Class search
- Add and remove favorite classes
- Filter favorite classes
- JavaScript event handling

**4. Schedule — schedule.html**

The Schedule page displays available dance classes and their schedules.

Endterm features:
- Schedule filtering by difficulty level
- Interactive selection
- DOM manipulation

**5. Contact — contact.html**

The Contact page provides studio contact information and a contact form.

Endterm features:
- JavaScript form validation
- Name, Email, and Message validation
- Error messages for invalid inputs
- Success message for valid inputs
- jQuery event handling and effects

The contact form demonstrates client-side validation and does not send data to a server.

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. Navigate between the website pages.
5. Test the JavaScript features.

An internet connection is required to load Bootstrap and jQuery from their CDNs.
