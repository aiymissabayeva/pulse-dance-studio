# Pulse Dance Studio

## About the Project

Pulse Dance Studio is a responsive multi-page website for a modern dance studio. The website provides information about the studio, dance classes, class schedules, and contact information.

## Pages

The website includes five pages:

- Home
- About
- Classes
- Schedule
- Contact

## Features

- Responsive navigation bar
- Dance class information
- Class schedule table
- Contact form
- Studio and trainer images
- Responsive design for desktop, tablet, and mobile devices
- Bootstrap grid system and utility classes
- Flexbox and CSS Grid layouts

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons
- Flexbox
- CSS Grid
- Media Queries

## Responsive Design

The website is designed to work on different screen sizes. Bootstrap and media queries are used to adapt the layout for desktop, tablet, and mobile devices.
